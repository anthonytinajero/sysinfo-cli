# System Information CLI

A lightweight macOS system information tool built using Bash, inspired by Neofetch.

Displays hardware and operating system information alongside custom ASCII art directly in the terminal.

## Features

- Custom ASCII art
- macOS version and kernel information
- CPU and GPU information
- System uptime
- Memory usage progress bar
- Disk usage progress bar
- Monochrome terminal design
- Automatic display on terminal startup (optional)

## Technologies

- Bash
- macOS command-line utilities
- AWK and Unix shell commands

## Installation

Clone the repository:

```bash
git clone https://github.com/anthonytinajero/sysinfo-cli.git
cd sysinfo-cli
```

Make the script executable:

```bash
chmod +x sysinfo.sh
```

Run:

```bash
./sysinfo.sh
```

## Purpose

This project was developed to strengthen my understanding of Unix-based operating systems, Bash scripting, system monitoring, and command-line tools.

## Platform

Developed and tested on macOS with Apple Silicon.
